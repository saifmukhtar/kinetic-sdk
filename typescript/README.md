## 📖 Overview

The `@kinetic-sdk/ts` package is a fully-typed, OpenAPI-generated TypeScript client for interacting directly with the local **Kinetic Daemon** via its REST API (default `http://127.0.0.1:16002`).

By leveraging this SDK, your web applications, desktop clients, and backend services can securely authenticate, register identities, broadcast raw gossip messages, and synchronize with the Kinetic P2P mesh network.

## 🚀 Installation

Install the package via npm:

```bash
npm install @kinetic-sdk/ts
```

## ✨ Quick Start

Before utilizing the SDK, ensure your Kinetic Daemon is running locally. To authenticate, you must provide the dynamically rotated bearer token generated by your Daemon (usually located at `~/.local/share/kinetic/tokens/publish.token` on Linux).

```typescript
import { Configuration, DefaultApi } from '@kinetic-sdk/ts';

// 1. Initialize the SDK Configuration
const config = new Configuration({
    basePath: 'http://127.0.0.1:16002',
    // Inject the dynamically rotated publish.token
    accessToken: 'YOUR_DAEMON_PUBLISH_TOKEN'
});

// 2. Instantiate the API Client
const kineticApi = new DefaultApi(config);

async function broadcastArticle() {
    try {
        // 3. Broadcast a Gossip message
        const response = await kineticApi.publish({
            author: 'alice.kin',
            title: 'Hello Kinetic!',
            summary: 'My first decentralized broadcast.',
            cid: 'Qm123...'
        });
        
        console.log('Broadcast successful:', response);
    } catch (error) {
        console.error('Gossip Broadcast Rejected:', error);
    }
}
```

## 🏗️ Architecture Stack
- **Target Environments**: Node.js, Browser (via bundlers like Vite/Webpack), React Native.
- **Language**: TypeScript (ES6+)
- **Network**: Local HTTP interactions with `kinetic-daemon`.
