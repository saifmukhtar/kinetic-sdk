## 📖 Overview

This API client was generated by the [OpenAPI Generator](https://openapi-generator.tech) project. The `kinetic-sdk` crate is a fully-typed Rust client for interacting directly with the local **Kinetic Daemon** via its REST API.

By leveraging this SDK, your native Rust applications, backend services, and CLI tools can securely authenticate, register identities, broadcast raw gossip messages, and synchronize with the Kinetic P2P mesh network.

## 🚀 Installation

Add the following to your `Cargo.toml` under `[dependencies]`:

```toml
kinetic-sdk = { path = "./kinetic-sdk" }
# Or if published to crates.io:
# kinetic-sdk = "0.1.1"
```

## ✨ Quick Start

```rust
use kinetic_sdk::apis::configuration::Configuration;
use kinetic_sdk::apis::private_api::{publish_post, PublishPostError};
use kinetic_sdk::models::PublishRequest;
use std::collections::HashMap;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut config = Configuration::new();
    config.base_path = "http://127.0.0.1:16002".to_string();
    config.bearer_access_token = Some("YOUR_DAEMON_PUBLISH_TOKEN".to_string());

    let request = PublishRequest {
        author: "alice.kin".to_string(),
        title: "Hello Kinetic!".to_string(),
        summary: "My first decentralized broadcast.".to_string(),
        cid: "Qm123...".to_string(),
    };

    let response = publish_post(&config, request).await?;
    println!("Broadcast successful: {:?}", response);

    Ok(())
}
```
